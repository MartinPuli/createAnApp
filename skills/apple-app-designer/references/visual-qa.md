# Visual QA checklist

| Area | Pass condition |
|---|---|
| Hierarchy | Primary task is obvious within five seconds |
| Layout | No overlap, vertical-letter wrapping, unusable truncation, or hidden action |
| Adaptivity | Compact/regular widths use intentional structures |
| Input | Touch, keyboard, pointer, Pencil, and focus paths work where promised |
| Type | Dynamic Type does not break meaning or completion |
| Accessibility | Labels, traits, order, contrast, motion, and targets are usable |
| States | Loading, empty, error, offline, permission, purchase, and restore are designed |
| Commerce | Price, period, renewal, entitlement, restore, terms, privacy, and close are clear |
| Marketing | Screenshots show real current UI and provable claims |

Preserve one screenshot per tested row with device/runtime/orientation/text-size/build metadata.
