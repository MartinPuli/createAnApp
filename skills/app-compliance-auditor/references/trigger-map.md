# Compliance trigger map

| Product change | Re-open at minimum |
|---|---|
| Add analytics/crash/ads/pixel/attribution SDK | Binary traffic, manifest, consent, privacy policy, App Store labels, vendor contract |
| Add account/cloud sync | Authentication, security, retention, export/deletion, breach response, labels/policy |
| Send content to an AI API | AI notice, purpose/consent, provider terms/training/retention, security, labels/policy, claims |
| Generate decisions or advice | Accuracy evidence, human oversight, safety/escalation, regulated-domain analysis |
| Accept user images/audio/video/PDF | File security, rights representation, storage/retention, privacy, deletion |
| Publish/share user content | Moderation, reporting, blocking, contact, takedown, repeat infringer, hosting/DMCA analysis |
| Add messaging/comments/community | Abuse, child safety, moderation staffing, block/report, law-enforcement/incident process |
| Add health/financial/legal/child features | Qualified counsel/professional review, special data rules, claims, age/consent, territory limits |
| Use synthetic talent/voice | Rights, disclosure, endorsement/testimonial truth, provenance |
| Add arbitration/class waiver | Jurisdiction, assent flow, accessibility, consumer-law/counsel review; do not paste a generic clause |
| Expand territory | Local consumer/privacy/tax/content/trader/export rules and localization |

Copyright registration or a DMCA agent is not a universal shield. Registration can affect enforcement remedies for owned works. A designated DMCA agent and compliant notice process may matter when hosting qualifying third-party content, but must be paired with actual statutory procedures and counsel analysis.
