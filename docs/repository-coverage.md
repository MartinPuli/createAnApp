# Objective-to-artifact coverage

| Requested capability | Primary skill | Supporting evidence |
|---|---|---|
| Search/select app idea | `$app-market-discovery` | Broad opportunity map, adversarial ranking, validation handoff |
| Validate an existing idea | `$app-idea-validator` | Frozen hypothesis, falsifiers, behavioral gates, explicit verdict |
| Validate market fit | `$app-idea-validator`, `$app-launch-operator` | Interest → activation → payment → retention distinction |
| Product design | `$apple-product-spec`, `$apple-app-designer` | Traceability, state/device/accessibility matrices |
| Development | `$ios-app-builder` | SwiftUI vertical slices, persistence, StoreKit, manifests |
| Apple MCP and other tooling | `$apple-agent-toolchain` | XcodeBuildMCP, native CLI, API, authority boundaries |
| Test simulator/persistence/commerce | `$ios-release-tester` | Executable inspector and release matrix |
| Apple Developer/App Store prerequisites | `$app-store-connect-preparer` | Agreements, roles, app record, signing, build |
| Exact App Store fields | `$app-store-connect-preparer` | Field guide, metadata and review dossier |
| Current Apple/Xcode requirements | `$app-store-connect-preparer`, `$ios-release-tester` | Dated primary-source baseline and upload gate |
| Exact UI/media measurements | `$apple-app-designer`, `$app-store-connect-preparer` | Control/type/icon/screenshot/preview reference |
| Subscriptions | `$apple-product-spec`, `$ios-app-builder`, `$app-store-connect-preparer` | Product lifecycle and first-group dependency rules |
| Privacy/legal/security/AI/IP | `$app-compliance-auditor` | Data/SDK/claim/provenance matrix and trigger review |
| Account deletion/login/UGC/regulated triggers | `$app-compliance-auditor` | Conditional Apple requirement matrix |
| Human inputs | `$app-store-launch-orchestrator` | Human handoff matrix and secret boundary |
| Rejections/resubmission | `$app-review-recovery` | Actual EULA, adaptive UI, group, returned-item, screenshot patterns |
| Website/creative/distribution | `$app-launch-operator` | Attribution, budget gates, honest AI creative rules |
| End-to-end orchestration | `$app-store-launch-orchestrator` | Lifecycle dossier, gate states, stop-ship rules |

This table proves structural coverage only. Each real app run must still produce current evidence for every applicable gate.
